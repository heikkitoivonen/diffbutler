# Code of conduct

DiffButler welcomes contributors of every background and experience level.

Be respectful and constructive. Critique ideas and code rather than people. Make room
for questions, differing opinions, and corrections. Respect people's time and privacy.

Harassment, discriminatory language, threats, sexual harassment, doxxing, and persistent
personal attacks are not acceptable in issues, pull requests, or other project spaces.

Maintainers may edit or remove inappropriate content, close disruptive discussions,
and restrict participation for repeated or serious violations. Enforcement should be
proportionate and protect those affected.

Report problems to a maintainer using an available private contact channel. If none is
listed, request a private contact without publishing personal or sensitive details.
Maintainers should handle reports discreetly and recuse themselves where involved.
